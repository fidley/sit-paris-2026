# We have agents, where are skills? 

This calls that we did before could be in fact create as skills and not agents. Let's then deep dive into topic of skills
and how they work with agents.

## No need to  sweat
``` There's a plenty of skills available online ```

If you go to [Skills.sh](https://skills.sh) you'll find lots of skill ready to download and use in your dev environment.
You'll find there also ARC-1 skills which you can easily download from git [Repo](https://github.com/arc-mcp/arc-1/tree/main/skills). Easiest way is to download full repo as zip
and then copy the full content of the skills folders into your special project under .github/skills folder.
